# Lab 1 solution — staged client

This folder is the **modernized `real-time-chat/client/`** that powers the
`solution/lab-01-modernize` branch.

It is staged here on `main` so the source-of-truth files are easy to read,
review, and update without needing to check out a separate solution branch.

What's in here:

- `client/` — the fully modernized chat client (React 19, Vite 6, function
  components, hooks, ref-as-a-prop, no `forwardRef`/`componentDidMount`).
- `lab01-ai-review.md` — reference write-up of three real bugs an AI
  assistant produced during the modernization pass, and how the solution
  fixes them. Use this as a benchmark for grading student submissions.
